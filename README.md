# Machine Facturas

Sistema de facturacao e gestao empresarial para o mercado angolano.

## Tecnologias

- Next.js
- React
- TypeScript
- Prisma ORM
- PostgreSQL
- Tailwind CSS
- Vitest

## Instalacao

Executa npm install para instalar as dependencias e npm run dev para iniciar a aplicacao na porta 3002.

## Seguranca

- Nunca publiques o ficheiro .env.
- Mantem palavras-passe, tokens e chaves privadas fora do repositorio.
- Confirma os requisitos fiscais aplicaveis junto da AGT.
